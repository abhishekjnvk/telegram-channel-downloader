# **Security Policy**

## **Reporting a Vulnerability**

Please report security vulnerabilities **privately** using GitHub's Private Vulnerability Reporting:

[++https://github.com/abhishekjnvk/telegram-channel-downloader/security/advisories/new++](https://github.com/abhishekjnvk/telegram-channel-downloader/security/advisories/new)

Do **not** open a public issue, pull request, or discussion for an undisclosed vulnerability.

What to include: affected version/commit, a description of the issue, the impact you believe it has, and a proof of concept or repro steps if you have one.

You can expect:

- an acknowledgement within **72 hours**;
- an initial severity assessment within **7 days**;
- a fix and coordinated public disclosure, normally within **14 days** of confirmation (we are happy to coordinate timing and credit, and to request  
a CVE/GHSA where appropriate).

## **Scope**

In scope: the code in this repository.

Out of scope: vulnerabilities in Telegram itself or in third-party dependencies (please report those upstream), and issues in your own Telegram account, session, or configuration.
